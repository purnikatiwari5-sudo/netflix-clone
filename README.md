# 🎬 Netflix Clone Website

A modern, responsive Netflix-inspired website built using **HTML5, CSS3, and Vanilla JavaScript**. This project recreates the look and feel of a streaming platform with movie browsing, search, category filters, trailers, and a personalized watchlist.

## ✨ Features

- 🎥 **Netflix-Inspired UI:** Dark theme, red accents, and a cinematic hero banner.
- 🔍 **Search Functionality:** Search for movies and TV shows by title.
- 🎞️ **Movie & TV Show Categories:** Filter titles by movies, TV shows, or all titles.
- 📺 **Trailer Playback:** Watch trailers through embedded YouTube videos.
- ℹ️ **Movie Information:** View posters, descriptions, release years, ratings, and durations.
- ➕ **My List:** Add or remove titles from your personal watchlist.
- 💾 **Local Storage:** Save your watchlist in the browser.
- 📱 **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.
- ⌨️ **Interactive Modals:** Open and close movie details and trailers using buttons or the Escape key.

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic elements.
- **CSS3** — Styling, responsive layouts, animations, and hover effects.
- **JavaScript** — Search, filters, movie cards, modals, trailers, and watchlist functionality.
- **Browser Local Storage** — Persistent watchlist data.
- **TMDB Image URLs** — Movie and series posters.
- **YouTube Embed** — Trailer playback.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub username and repository name.

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Website

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for a convenient development experience.

No frameworks or package installations are required.
